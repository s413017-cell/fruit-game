# 🍉 水果切切樂 (Fruit Ninja Web)

## 📖 1. 作品名稱
**水果切切樂 / Fruit Ninja Web**

---

## 🎮 2. 遊戲玩法與視覺呈現

  <img src="images/gameplay.png" alt="遊戲畫面預覽" width="700">

* **視覺風格**：採用 HTML5 Canvas 搭配 Tailwind CSS 打造高質感介面，包含木紋質感背景、外圍暗角陰影與透明模糊（Backdrop Blur）彈窗。
* **核心機制**：
  * **拋物線飛出**：水果與道具從螢幕下方隨機拋出，呈現自然重力墜落軌跡。
  * **劃線切擊**：支援滑鼠拖曳與手機觸控劃線，刀光具有黃色光暈（Glow Shadow）特效。
  * **豐富特效**：切開時水果會分開飛散，畫布上留有漸隱果汁印記（Juice Splatter）、果汁微粒與即時浮動文字（如 +10, COMBO!）。
  * **倒數機制**：60 秒限時挑戰，時間結束後進入結算畫面。

## 🤖 3. 使用的 AI 提示詞 (Prompts)

在本專案開發過程中，主要使用了以下 Prompt 進行單一檔案遊戲的生成：

> **請使用單一 HTML 檔案製作一款質感精美的「水果切切樂（Fruit Ninja）」網頁遊戲。請確保程式碼完全可執行且包含完整的 HTML、CSS 與 JavaScript。**
> 
> **1. 技術規範與視覺風格**
> * **單一檔案**：所有邏輯、樣式與繪圖均寫在單一 `.html` 檔案中。
> * **介面與樣式**：使用 Tailwind CSS 打造高質感的 HUD 頂部列與透明模糊（backdrop-blur）彈窗。
> * **背景繪製**：使用 HTML5 Canvas 動態繪製木紋質感背景與外圍暗角陰影。
> * **圖形繪製（無外部圖片）**：所有水果（蘋果、西瓜、香蕉、鳳梨、草莓、柳橙）、水果切半圖案、道具（加時鬧鐘、雙倍星星）及炸彈，均使用內嵌 SVG (Data URL) 預渲染至 Canvas 畫布。
> * **音效（無外部音訊檔）**：使用 Web Audio API 合成即時音效（揮刀切擊聲、加分音效、炸彈爆炸聲）。
> 
> **2. 遊戲核心物理與機制**
> * **水果拋物線**：水果與道具從螢幕下方以隨機角度與初速拋出，呈自然的拋物線重力墜落。
> * **切擊檢測**：支援滑鼠拖曳與手機觸控劃線，精準計算刀光線段與水果圓形的相交（Intersection Detection）。
> * **刀光特效**：繪製具有黃色光暈（Glow Shadow）與圓角連線的即時揮刀軌跡。
> * **粒子特效**：包含水果切半飛散、果汁印記淡出、飛濺果汁微粒與浮動文字。
> 
> **3. 道具與道具計分規則**
> * **基礎水果**：切中得 10 分。
> * **連擊（Combo）**：一次劃過 2 個水果額外加分，3 個以上獲得大額加分與 COMBO 浮動文字。
> * **加時鬧鐘 (Clock)**：切中獲得 +5 秒額外時間與 Bonus 分數。
> * **雙倍星星 (Star)**：切中啟動 10 秒內得分 2 倍 (2X) 狀態，頂部顯示倒數 Badge。
> * **炸彈 (Bomb)**：切中扣除 15 分並播放爆炸音效。
> 
> **4. UI 流程與遊戲狀態**
> * **頂部 HUD**：實時顯示當前 SCORE、剩餘倒數 TIME、雙倍得分（2X）狀態。
> * **開始彈窗 (Start Modal)**：顯示遊戲名稱、規則說明與「開始遊戲」按鈕（點擊時初始化 Web Audio 音訊）。
> * **結算彈窗 (Game Over Modal)**：60 秒倒數結束後彈出，顯示最終得分與「再玩一次」按鈕。

## ✅ 4. 已完成的功能與技術亮點
- [x] **Web Audio API 無外部音效技術**：
  - `playSliceSound()`：結合 Bandpass Filter 噪訊與 Triangle 波形模擬真實揮刀風聲與切擊聲。
  - `playBonusSound()`：Sine 波上升音階模擬獎勵音。
  - `playBombSound()`：Sawtooth 波低頻模擬爆炸聲。
- [x] **離屏 Canvas 預渲染 (SVG Image Pre-rendering)**：建立 `fruitCanvasMap` 解決 Canvas 渲染複雜向量圖形的效能瓶頸。
- [x] **動態拋物線物理演算法**：依據螢幕高度動態計算拋物線頂點（Screen Top 15%~33%），確保水果每次飛入均在最佳切擊區域。
- [x] **切擊檢測與連擊 (Combo) 系統**：精準計算劃線軌跡與水果碰撞，並觸發連擊加分。
- [x] **多樣化道具系統**：支援「加時鬧鐘 (+5s)」與「雙倍星星 (2X 得分)」。
- [x] **炸彈扣分機制**：切中炸彈扣 15 分並觸發爆炸視覺與音效。
- [x] **響應式與跨平台支援**：完整支援桌面端滑鼠與行動端觸控劃線。

## 🕹️ 5. 操作方式
* **電腦端**：按住 **滑鼠左鍵** 並拖曳滑鼠劃出刀光，切開飄過的水果與道具。
* **手機/行動端**：使用 **手指在螢幕上滑動** 劃出刀光進行切擊。
* **避開炸彈**：劃過黑色炸彈會扣 15 分，請小心避開！
* **優先切擊道具**：
  * ⏰ **鬧鐘**：增加 5 秒遊戲時間。
  * ⭐ **星星**：獲得 10 秒內得分 2倍效果。
